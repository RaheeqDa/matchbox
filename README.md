# Matchbox

Matchbox is a simple, responsive website that helps students choose the right AI tool for a task. It compares popular tools for writing, coding, research, studying, image creation, and presentations, and includes examples of student projects made with AI.

This project was created with plain HTML, CSS, and JavaScript, so it can be hosted as a static website.

## Features

- Pick a task and get a suggested AI tool
- Compare ChatGPT, Claude, Gemini, and Copilot
- Filter an example project gallery
- Responsive layout for phones, tablets, and computers
- Mobile navigation and simple interactive animations

## View the project

Open `index.html` in a web browser to use the website locally.

No package installation or local server is required.

## Files

- `index.html` — website content and page structure
- `styles.css` — design and responsive layouts
- `script.js` — task recommendations, mobile menu, and project filters
